# Todoアプリ挫折の課題リサーチ（LP課題ベース訴求用コピー素材）

作成: 2026-07-12 / deep-research（24ソース・110クレーム→検証通過18→9系統）
用途: taskLap_landing の課題ベース書き換えのコピー素材。
注意: 根拠の大半はブログ・一次証言エッセイ・ベンダー記事。App Storeレビュー/Reddit生スレ/日本語X・noteの生の声の直接収集は未達（→追加調査の余地）。「ユーザーの声」としての引用は不可、言い回しの参考に留める。

## 課題カテゴリと具体フレーズ

### A. 管理が第二の仕事になる（信頼度: 高・最多ソース）
- 「アプリを管理するパートタイムの仕事が増えただけだった」
- 「1時間かけてラベル・優先度・期限を完璧に整えて、アプリを閉じて、タスクは一つもやらなかった」
- 「アプリが悪いんじゃない。始める前から多くを要求されすぎるのが問題だった」
- → TaskLap対応: 登録不要・設定ほぼゼロ・グループだけのシンプル整理
- 出典: anshraj7(Medium) / themanagersprism / getinflow.io / arXiv 2603.17258（ADHD成人22名: 整理に実行より時間を使う）

### B. 溜まった未完了→罪悪感→開くのが嫌になる（信頼度: 高）
- 「ホーム画面の赤い数字が、失望した親みたいにこっちを見ている」
- 「期限切れタスクの山は、開く気力を積極的に削ぐ」
- 「挫折の後の自責が、次の挑戦も同じ理由で失敗させる」
- → TaskLap対応: 持ち越しレビュー（朝、責めずに仕分け直す。赤で脅さない）
- 出典: anshraj7 / getinflow.io / tiimoapp / thawly.ai(傍証) / zapier(傍証)

### C. 静かな挫折・アプリ渡り歩き（信頼度: 中）
- 「どのアプリも約2週間、コントロールしている錯覚をくれた。そして静かに開かなくなった」
- 「11個のアプリを試して、全部やめた」
- ※怒って消すのではなく「静かに開かなくなる」が核心の言い回し
- 出典: anshraj7 / themanagersprism（一次証言2本）

### D. 決断疲れ（ADHD傾向層に強い / 一般にも有効）（信頼度: 中、定量裏付けあり）
- 「どれからやるか決めるだけで疲れる」「選べないから、開かない」
- リストが長いほど、脳は同じ選択肢をループするか決断自体を回避する
- 査読研究: ADHD成人の82%が意思決定困難を頻繁に経験（European Psychiatry 2025, PMC12438291）
- → TaskLap対応: フォーカスモード＝1画面1タスク・完了/スキップの2択（そもそも選ばせない）
- 注意: 「決断の電池」比喩の基盤(ego depletion)は科学的係争中。断定表現は避ける

### E. アプリを開くこと自体を忘れる（ADHD傾向層）（信頼度: 中）
- 「開かないリストは、存在しないのと同じ」
- 注意: ウィジェット等で緩和されるため「全アプリが失敗する」と絶対化しない
- 出典: lifeskillsadvocate.com（展望記憶の研究引用あり）

### F. 新奇性が切れる「2週間の死のスパイラル」（ADHD傾向層）（信頼度: 中）
- セットアップのドーパミン → 新奇性消失 → 1日抜ける → 罪悪感 → 回避
- 出典: tiimoapp（ベンダーブログ、INCUP/Dodsonと整合）

### G. 機能過多＝視覚的ノイズ（信頼度: 中）
- 「欲しいのはリストだけなのに、機能が多すぎて散らかって見える」
- 傍証: ミニマル代替アプリで完了率49%→84%の体験記事(XDA)
- 出典: zapier.com

### H. 繰り返しタスクの硬直性（信頼度: 高・日本語圏一次証言）
- Todoist: 延滞中の繰り返しタスクは1回分だけ完了できず、1つ完了で延滞分が全部流れる
- 原文: 「遅れている繰り返しタスクを部分的に完了させることはできません」(jsnotice.com 2023、2026年時点でも公式ヘルプが同挙動)
- → TaskLap対応: チェックリストはリセットして毎回まっさらに再利用
- 注意: 「4ヶ月の家賃滞納で実害」の具体エピソードは検証で反証済み(0-3)。使わない

### I. ストリーク断絶→やる気消滅（信頼度: 中・言い回し参考のみ）
- 「旅行や風邪で21日のストリークが消えた瞬間、全部どうでもよくなった」
- what-the-hell effect / Duolingo Streak Freezeの存在と整合
- 注意: 出典は競合アプリのマーケブログ。「ユーザーの声」として使わない
- → TaskLap対応: ストリークで縛らない設計（持ち越しレビューは翌日リセットの発想）

## 使用禁止（検証で反証されたフレーズ）
- 「タスクの墓場」「約1か月でdozens of overdue」等の数値付き断定（thawly.ai、0-3で棄却）
- 「追加し続けてレビューしないのが破綻の核心機構」という断定（zapier、0-3で棄却）
- jsnoticeの「家賃4ヶ月滞納の実害」エピソード（0-3で棄却）
